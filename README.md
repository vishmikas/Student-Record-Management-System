# 🎓 STUDENT RECORD MANAGEMENT SYSTEM

A robust Java-based desktop application for efficient student data and result management. This project demonstrates real-world software engineering practices including layered architecture, database integration, and clean code principles.

---

## 🚀 PROJECT SUMMARY

The Student Record Management System is designed to simplify how student information and academic results are handled in an educational environment.

It provides a structured, scalable, and user-friendly solution for managing student records using Java, MySQL, and the DAO design pattern.

---

## 💡 WHY THIS PROJECT STANDS OUT

-  Built using a clean layered architecture (UI → Service → DAO → Database)
-  Demonstrates strong Object-Oriented Programming (OOP) principles
-  Uses JDBC for real-world database connectivity
-  Applies DAO pattern for maintainable and scalable code
-  Simulates a real industry-level CRUD application

---

## ✨ KEY FEATURES

-  Add and manage student records
-  Insert and update student results
-  View and track academic performance
-  Structured database interaction using DAO pattern
-  Persistent data storage with MySQL
-  User-friendly desktop interface using Java Swing

## 📂 PROJECT STRUCTURE

The project follows a clean and maintainable structure:

-  dao → Handles database operations
-  db → Database connection setup
-  model → Data models (Student, Result)
-  service → Business logic layer
-  ui → User interface components
